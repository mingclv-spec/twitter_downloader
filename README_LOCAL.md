# X-Trans (On-Premise 本地电脑运行版本)

> **分支说明**：当前分支为 `on-premise`，专为在个人电脑（Windows、Mac、Linux）或本地内网服务器私有化运行设计。
> **100% 免 API Key · 数据完全本地处理 · 零服务器费用**

---

## ⚡ 极速启动指南 (1-Click Run)

### Windows 用户：
直接双击根目录下的 **`start.bat`** 即可：
- 自动检测并安装依赖
- 自动启动服务并监听 `http://localhost:3000`
- 浏览器访问 `http://localhost:3000` 即可使用

### Mac / Linux 用户：
在终端中进入项目目录，执行：
```bash
chmod +x start.sh
./start.sh
```
浏览器打开 `http://localhost:3000` 即可使用。

---

## 🛠️ 本机运行特性 (On-Premise Features)
1. **零 API Key 需求**：内置无需 Key 的推特视频解析引擎和高精度双语神经网络翻译。
2. **离线样例演示**：内置 3 个典型推特视频（AI 发布会、星舰发射、产品设计），即使断网也可即点即测。
3. **微信一键分发**：直接在本地生成视频号 9:16 分享海报、朋友圈文案与内嵌双语字幕的压制 MP4。
4. **多端互通**：在同一局域网下，手机浏览器输入 `http://电脑局域网IP:3000` 即可直接无线使用。

## 🌿 分支对比
- **`on-premise`**（当前分支）：专为个人 PC 本机私有化离线运行优化。
- **`online`** 分支：专为 Docker、Render、Railway 等线上公网云平台托管优化。
